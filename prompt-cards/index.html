三個技巧 做出小工具 出錯怎麼辦 想點子 放上網址

三個技巧

技巧 1

說清楚：給誰用、要做什麼

照這個句型填空

我想做一個＿＿＿，給＿＿＿使用。

例子

我想做一個「今天吃什麼」的小工具，給一般人使用，不需要懂電腦，只要會上網和點擊就能操作，連家裡的長輩都能輕鬆看懂。

不用寫很長，這兩件事講清楚就夠了。

技巧 2

先複述給我聽，再問我問題

開始前，請先用三句話說明你理解的需求，再最多問我三個會影響結果的問題。我確認後，你再開始做。

它複述錯了，你一句話就能糾正，比整個做完才發現方向不對，省下很多時間和額度。

技巧 3

全部說出來，但一次只改一個地方

目前我覺得有這些問題：
1. ＿＿
2. ＿＿
3. ＿＿
這一輪請保留所有功能，只修改第 1 點，其他部分請不要更動。我們一個一個來。

先讓它知道全貌，這一輪只動一處，穩穩往前走。

一步一步做出「今天吃什麼」

小卡 1

先只列清單，不要急著做工具

我想做一個「今天吃什麼」的小工具，給一般人使用。使用者不需要懂電腦，只要會上網和點擊就能操作，介面要簡單直覺、字要大，連家裡的長輩都能輕鬆看懂。請先幫我列出 100 種台灣人常吃的餐點，分成「早餐、午晚餐、小吃、甜點、飲料」五類，每類 20 個左右。先只列清單，不要做工具，我確認後再進行下一步。

項目當然可以更多，但東西越多越容易出錯。寧可先做簡單的，之後再以這個版本為基礎修改。

小卡 1 補充

清單不對，都可以跟 AI 溝通

請刪掉重複的項目，並補到每類剛好 20 個，其他保持不變。

清單不夠、有重複，甚至項目不是你想要的，都可以直接說。這裡舉例的是「刪掉重複的項目」。

小卡 2

清單沒問題了，現在做成網頁（HTML 檔）

清單沒問題了，請用這份清單做成一個 HTML 檔（網頁檔），存起來就能直接用瀏覽器打開：
- 畫面上有「什麼都可以」加五個分類按鈕，選一類後，按中間的大按鈕「幫我決定」
- 只從選到的那一類隨機抽，「什麼都可以」就從全部抽，連續兩次不要抽到一樣的
- 結果用大字顯示
- 字體和按鈕都要大，手機與電腦都好按
- 先做最簡單的版本，不要加我沒有要求的功能
小卡 3

基本版沒問題了，但我還想加點什麼

基本版沒問題了，請保留目前的畫面和按鈕。只新增兩個功能：
1. 可以自己輸入新的選項，加進目前選到的分類
2. 每個選項旁邊有一個「刪掉」按鈕
新增和刪除的選項要記住，重新整理頁面也不會消失。其他部分請不要更動。
小卡 4

大致上都喜歡，但顏色跟編排不喜歡，該怎麼辦？

貼這句，把＿＿填上

我原本要的是＿＿。
目前問題是＿＿。
請保留所有功能，只修改＿＿。
完成後我會檢查按鈕是否仍然夠大、功能是否正常。

填空範例

  • 原本要的：溫暖、讓人有食慾
  • 目前問題：顏色太冷、整體太像工具
  • 只修改：配色和標題文字，改成暖色系、標題用親切的口吻
小卡 5

我不只想要抽卡，還想省下上網查詢的時間

請保留目前所有功能，只新增一個功能：
1. 畫面上方加一個輸入框，提示文字是「你現在在哪裡？例如：鳳山站」
2. 抽到結果後，下方出現「找附近的店」按鈕
3. 按下去用 Google 地圖搜尋「抽到的餐點名稱 + 輸入框的地點」，在新分頁開啟
4. 輸入框留空時，只搜尋餐點名稱加「附近」
其他部分請不要更動。

出錯怎麼辦

小卡 6

用三句話告訴它哪裡不對

貼這句，把＿＿填上

我按了＿＿，我預期＿＿，但實際上＿＿。請只修這個問題，其他部分不要更動。

範例

我按了「刪掉」按鈕，我預期那一項會消失，但實際上是別的項目消失了。請只修這個問題，其他部分不要更動。
小卡 7

更新之後，之前有的東西不見了，該怎麼辦？

貼這句，把＿＿填上

更新之後，原本有的＿＿不見了。請把它加回來，並保留目前所有其他功能，其他部分請不要更動。

範例

更新之後，原本有的「找附近的店」按鈕不見了。請把它加回來，並保留目前所有其他功能，其他部分請不要更動。

小提醒：每次滿意的版本先另存一份，真的壞了還能回到上一版。

做完以後，想點子

小卡 8

讓 Claude 當你的點子夥伴

請看一下目前這個工具，你覺得還可以加什麼有趣的功能？先給我三個點子，我選了你再做。

你來選，它來做，方向盤永遠在你手上。

小卡 9

如果這三個點子都不喜歡，該怎麼辦？

這三個我都不太喜歡。我想要的方向是＿＿。請再給我三個不一樣的點子，我選了你再做。

說不出方向也沒關係，只說「請換個完全不同的角度再想三個」也可以。

小卡 10

我有其他點子，回家想玩玩，該怎麼做？

先講想法，再接上這句

幫我做一個好玩的 APP。
開始前，請先用三句話說明你理解的需求，再最多問我三個會影響結果的問題。我確認後，你再開始做。

想法再模糊也沒關係，讓它先問你，就能一起把方向問出來。

進階：放上網址，變成手機圖示

進階 總覽

從頭到尾：交給 Claude，或自己來

交給 Claude

  • 做出網頁、改功能和外觀
  • 想儲存庫的名字
  • 看你的截圖，告訴你下一步
  • 解釋英文畫面和錯誤訊息

自己來

  • 申請 GitHub 帳號（要收驗證碼）
  • 下載檔案，改名 index.html
  • 建立儲存庫、上傳檔案
  • 開啟 Pages（網頁發布）
  • 手機加到主畫面

Claude 只能碰你授權的儲存庫，授權隨時可以取消。

進階 A

申請 GitHub 帳號

  1. 打開 github.com（GitHub 網站），按「Sign up（註冊）」
  2. 電子郵件可以用 Gmail，照畫面設定密碼
  3. 取一個「使用者名稱（Username）」，它會出現在你的網址裡，請取一個你願意公開的名字
  4. 到信箱收驗證碼，輸入就完成了

網站是英文介面，照著按鈕的位置按就好。如果畫面上有「Continue with Google（用 Google 繼續）」，也可以直接點它用 Gmail 登入。

進階 B

把做好的網頁檔放上去

  1. 把做好的網頁檔下載下來，檔名改成你想要的英文單字；想簡單一點，打 index.html 就好（網頁首頁檔，照著打、全小寫）
  2. 登入 GitHub，按右上角「＋」，選「New repository（新增儲存庫）」
  3. Repository name（儲存庫名稱）取個名字（例如 eat），選「Public（公開）」，按「Create repository（建立儲存庫）」
  4. 按「uploading an existing file（上傳現有檔案）」，把 index.html 拖進去
  5. 按下方綠色的「Commit changes（提交變更）」

「Public（公開）」表示拿到網址的人都看得到，不要放私人資料。用 index.html 網址最短；改成別的英文名字也可以，但網址後面要多打那個檔名（例如 .../eat.html）。

進階 C

打開 Pages，拿到你的網址

  1. 進到你的儲存庫（repository），按上方的「Settings（設定）」
  2. 左邊選單選「Pages（網頁發布）」
  3. Branch（分支）選「main（主要分支）」，資料夾維持「/ (root)（根目錄）」，按「Save（儲存）」
  4. 等 1 到 2 分鐘，重新整理頁面，上方會出現你的網址

網址長得像「你的名字.github.io/eat」，把這個連結存起來，傳給家人朋友也能用。

進階 D

加到主畫面，點一下就打開

iPhone（Safari 瀏覽器）

  1. 打開你的網址
  2. 按下方的「分享」圖示
  3. 選「加入主畫面」
  4. 按「新增」

Android（Chrome 瀏覽器）

  1. 打開你的網址
  2. 按右上角的「⋮」
  3. 選「加到主畫面」或「安裝應用程式」
  4. 按「新增」或「安裝」

不同手機和瀏覽器的字樣可能有點不一樣，找長得像的選項就對了。

選修

自訂手機圖示

沒設定的話，手機會用網頁的截圖或文字當圖示。想換成自己的圖：

  1. 準備一張正方形的 PNG 圖（做法看下面），檔名取 icon.png
  2. 請 Claude 加上圖示設定（貼下面這句）
  3. 把 icon.png 和 index.html 一起上傳
  4. 手機上舊圖示先刪掉，再重新「加到主畫面」

貼給 Claude 的話

請幫我在這個網頁加上手機主畫面圖示的設定，圖示檔名是 icon.png（正方形 PNG 圖），其他部分請不要更動。完成後告訴我要把哪些檔案一起上傳。

沒有圖檔？自己做一張

  • 用 Canva（線上設計網站）或其他 AI 做一張
  • 正方形 PNG，建議做 1024×1024 像素，再請 Claude 縮成需要的尺寸
  • 不確定尺寸，直接問 Claude
  • 背景鋪滿、不要透明，重要的東西放中間，不要放太小的字

貼給 Claude 的話（附上圖）

請把這張圖縮成 512×512 像素的 PNG，檔名取 icon.png。

如果 Claude 沒辦法輸出圖檔，也可以在 Canva 直接調整尺寸再下載。不同手機看到的圖示樣子可能略有不同。

進階 E

找到連接器，授權給 Claude

  1. 電腦版：聊天視窗左下按「＋」，滑鼠移到「Connectors（連接器）」，選「Manage connectors（管理連接器）」
  2. 找到 GitHub，按「Connect（連接）」，登入並勾選要授權的儲存庫
  3. 回到對話，直接說你想改哪個儲存庫、哪個檔案

可以這樣說

請看我 GitHub 上儲存庫＿＿裡的 index.html。請保留目前所有功能，只修改＿＿，其他部分請不要更動。

手機版目前很難找到連接器，建議用電腦連。連好後，手機重新登入就會出現。

Claude 只能碰你授權的儲存庫，不想用時隨時可以取消授權。能做到什麼要看授權和工具；做不到時 Claude 會告訴你，到時就複製它改好的內容，自己貼回 GitHub。

進階 F

卡住了，把畫面截圖給 Claude

我附上目前畫面的截圖。我想要＿＿，請告訴我下一步要按哪裡。

看不懂的英文，也可以直接問 Claude 這個按鈕是什麼意思。截圖前，先把密碼和驗證碼遮起來。

你說得越清楚，它就越懂你。
